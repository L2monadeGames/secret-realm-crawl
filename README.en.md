# Secret Realm Crawl

**비경회기(祕境廻起)** — a browser-based, text-driven xianxia RPG.

[Play for free](https://secret-realm-crawl.l2knmn.chatgpt.site) · [한국어 안내](README.md)

Current game version: **v0.1.0**

## Available now

- Explore a xianxia world through text and choices.
- Choose your next area and move forward. Returning along a chosen route is not supported.
- Fight by choosing Attack, Defend, or Circulate Qi (운기).
- Learn cultivation techniques and equip insights for combat.

The game is in early development. A long-form story and reincarnation system are not currently available features.

## Language support

The game currently supports **Korean only**. Support for other languages is planned for the long term, with no announced release date. This English README introduces the game; it does not indicate English gameplay support.
