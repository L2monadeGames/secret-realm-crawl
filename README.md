# 비경회기(祕境廻起)

**Secret Realm Crawl** — 브라우저에서 즐기는 텍스트 선협 RPG.

[무료로 플레이하기](https://secret-realm-crawl.l2knmn.chatgpt.site) · [English guide](README.en.md)

현재 게임 버전: **v0.1.1**

## 현재 즐길 수 있는 것

- 텍스트와 선택지를 통해 선협 세계를 탐험합니다.
- 다음 지역을 선택해 앞으로 나아갑니다. 선택한 길을 되돌아가는 방식은 지원하지 않습니다.
- 공격·방어·운기 중 행동을 선택하며 전투를 진행합니다.
- 공법을 배우고, 깨달음을 장착해 전투에 활용합니다.

초기 개발 단계인 게임입니다. 장기 서사와 다회차 시스템은 현재 제공되지 않습니다.

## 언어 지원

현재 게임은 **한국어만 지원**합니다. 다른 언어 지원은 장기적으로 예정되어 있으며, 제공 시기는 정해지지 않았습니다. 영어 README는 게임 소개 안내이며 영어 플레이 지원을 뜻하지 않습니다.

## 제보와 제안

[GitHub Issues](https://github.com/L2monadeGames/secret-realm-crawl/issues/new/choose)에서 버그나 개선 아이디어를 알려 주세요. 버그 제보에는 재현 순서, 기대한 결과와 실제 결과, 게임 버전과 브라우저를 적어 주시면 도움이 됩니다. 자세한 안내는 [제보 안내](CONTRIBUTING.md)를 참고해 주세요.

이슈와 첨부 자료는 공개됩니다. 개인정보, 비밀번호, 인증 토큰, 전체 저장 데이터나 관리 화면을 올리지 마세요.

## 이 저장소와 권리 안내

이 저장소는 게임의 공개 소개와 제보를 위한 공간입니다. 게임 개발 소스는 포함하지 않습니다.

현재 게임을 무료로 플레이할 수 있다는 사실은 게임 코드나 자산의 오픈소스 공개 또는 자유로운 재사용을 뜻하지 않습니다. 별도로 허용된 범위를 제외한 권리는 각 정당한 권리자에게 유보됩니다. 외부 라이브러리·아이콘·폰트 등에는 각각의 라이선스가 적용됩니다.
